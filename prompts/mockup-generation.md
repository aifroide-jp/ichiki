## 案件情報（埋める）

```
プロジェクト名 :
サイトの目的   :
配色・トーン   : （例: 落ち着いた緑基調。自然・公共施設らしく）
参考にするサイト: （URL。「モダンに」等の抽象語より具体例のほうが効く）
リプレイス前   : （既存サイトのURL、または「新規」）
画像の場所     : （ディレクトリパス。images/meta.yaml も必ず用意すること）
ページ構成     :
  - / （トップ）
  - /about/strategy （固定ページ）
  - /spots/ （一覧）+ /spots/<slug> （詳細 = CPT: spot）
  - ...
CPT一覧        : spot / center / event / news など
フォーム       : お問合せ / 参加申込 など
```

### ここから下をAIに渡す

あなたは WordPress 化を前提としたモックアップを作ります。  
**やり取り・説明・出力メッセージはすべて日本語で書いてください。**

## 1. まず規約を読む

**`.claude/ichiki/rules/vocabulary.md` を最初に読んでください。**  
そこに書かれた宣言（`data-*`）とルール（L01〜L31）が守るべき全てです。  
このファイルには規約を書いていません。**要約も抜粋も信用せず、語彙そのものを読んでください。**

デザイン（色・レイアウト・雰囲気）は主観なので自由です。  
構造（何が編集対象か・何が CPT か・どこが共通か）は機械が変換するので、宣言が必須です。  
**推測させないでください。** 宣言が無いものは変換器がエラーで停止します。

## 2. 書く

ページ構成に沿ってモックを書きます。宣言の付け方は語彙に従ってください。

## 3. lint が通るまで直す

```bash
node .claude/ichiki/bin/ichiki.js lint <mockupDir>
```

**一発で完璧に書こうとしないでください。** 語彙は31ルールあり、1回で全部守るのは現実的でない。  
lint の指摘がそのまま作業リストになります。error が 0 になるまで繰り返してください。

同じ種類の指摘がまとまって出たら、まとめて直せます  
（実測: `data-acf-type` の付け忘れ53件を一括で処理できた）。

## 4. 残りの検査も通す

```bash
node .claude/ichiki/bin/ichiki.js a11y <mockupDir>   # WCAG2AA。error 0
node .claude/ichiki/bin/ichiki.js scan <mockupDir> <out>   # 未分類（取りこぼし）0
```

## 5. 未宣言テキストの一覧をお客様に出す

lint の **L20** が「宣言の無いテキスト」を warn で列挙します。これは取りこぼしではなく  
**「更新対象外の固定文言」** です。お客様に提示して合意を取ってください。

---

## モックは合意まで何度も触る

お客様に見せて直す工程が何周も回ります。**そのたびに宣言が腐ります。**

```
セクションを足して data-section を忘れる
文言を差し替えて data-acf を落とす
<head> をいじって <title> を巻き込む
```

どれも静かに起きます。**触ったら毎回 lint を通してください。**  
数十ページでも1秒かかりません。負担になりません。

見た目は変わって構いません（変えるために見せているので）。**宣言が保たれることだけが条件です。**

---

## デザインの方針

「AIっぽさ」を避けてください。具体的に避けるもの:

- 見出しに絵文字を使う
- グラデーションの多用
- 等間隔3列カードの単調な反復
- 意味のない装飾アイコンの羅列
- 「〜しませんか？」調の勧誘コピー
- フォント指定が `system-ui` / `Inter` だけ

抽象的な「モダンに」より、**参考サイトを具体的に指定されたらそれに寄せてください。**

## 完成の定義

```bash
node .claude/ichiki/bin/ichiki.js lint <mockupDir>          # → exit 0（error 0件）
node .claude/ichiki/bin/ichiki.js a11y <mockupDir>          # → exit 0（error 0件）
node .claude/ichiki/bin/ichiki.js scan <mockupDir> <out>    # → 未分類 0
```

3つすべてが通り、かつ **L20 の一覧をお客様に提示して「これらは更新対象外」の合意が取れて**、  
初めて完成です。

**lint を通すためにルールを緩めてはいけません。**  
ルールが実態に合わないと判断した場合は、勝手に回避せず報告してください。  
語彙を直すかどうかは人が決めます。
